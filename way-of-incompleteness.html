    Symbol guide

    The language of arithmetic needs very few symbols. Everything else on these pages is either ordinary logic or shorthand for talking about the system from outside.

    The language of arithmetic

    0
    ZeroThe only constant. Every other number is built from it.
    S
    SuccessorSx means x + 1. There is no symbol for 2; it is written SS0, the successor of the successor of zero. A string of S's in front of 0 is called a numeral.
    +
    AdditionDefined by two axioms: x+0=x and x+Sy=S(x+y).
    ·
    MultiplicationDefined by x·0=0 and x·Sy=(x·y)+x. Without it, arithmetic becomes complete (Presburger, chapter XI).
    =
    EqualsEvery atomic sentence of arithmetic is an equation between two terms.
    x, y, p, s
    VariablesStand for natural numbers. A variable left free in an axiom, as in x+0=x, is read as "for every x".
    ( )
    GroupingS(x+y) is the successor of the sum, not Sx + y.
    ℕ
    The natural numbers0, 1, 2, 3, … with ordinary + and ·. "True" in these chapters means true in ℕ.

    Logic

    ¬
    Not¬(0=S0): zero is not one.
    →
    If … thenA → B is false only when A is true and B is false.
    ↔
    If and only ifBoth sides are true or both are false. G ↔ ¬Prov(⌜G⌝) says G holds exactly when G is not provable.
    ∃
    There exists∃p Proof(p, s): some number p is a proof of s.
    ∴
    ThereforeMarks a conclusion on the chapter IV plate.

    Talking about the system

    T
    A theoryAny formal system that is consistent, effectively axiomatized, and strong enough for basic arithmetic.
    PA, Q
    Peano and Robinson arithmeticPA has the arithmetic axioms plus induction. Q drops induction; it is already enough for the first theorem.
    ⊢  ⊬
    Proves, does not proveT ⊢ A: A has a proof in T. This is a statement made about T, from outside it.
    φ, ψ
    FormulasGreek letters stand for arbitrary formulas. φ(x) has one free variable x.
    ⌜A⌝
    Gödel number of AInside a formula it means the numeral for A's code, SSS…0. This is how one sentence can mention another.
    Proof(p, s)
    Proof relationp codes a correct proof whose last line is the formula coded by s. A mechanical check.
    Prov(s)
    ProvableShort for ∃p Proof(p, s). The system's own word for "has a proof".
    Con(T)
    T is consistent¬Prov(⌜0=S0⌝): T never proves 0 = 1. Any contradiction would yield that, so this captures consistency.
    G, G₁, G₂
    Gödel sentencesG is T's unprovable sentence. G₁ belongs to T + G, G₂ to T + G + G₁, and so on.
    ε₀
    Epsilon-noughtThe first ordinal beyond ω, ωω, ωωω, …. Induction up to ε₀ proves Con(PA) and Goodstein's theorem; PA cannot.
