  1. Seal it and send opens GitHub with your letter already written in. You will need a free GitHub account.
  2. Press Commit changes and then Propose changes, and then Create pull request. GitHub makes your own copy along the way.
  3. The letter goes into the box once it has been read. That can take a few days.
  4. No GitHub account? Use Copy it for the Wizard and send it by text or email. The Wizard can post it for you.

Adding photos from your visit: upload them to the visit notes and open a pull request in the same way. Only send photos of places, not of people. Phones store where a photo was taken, and GitHub keeps that, so turn off location for the camera first. The box refuses photos that still have a location in them.

Sign the box and you are the Wizard's Apprentice, for as long as you stay.
