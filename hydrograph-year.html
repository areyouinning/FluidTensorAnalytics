Hydrograph Synth

Each note's envelope is fitted to an annual hydrograph. The rising limb sets the attack, the peak recession sets the decay, baseflow sets the sustain level, and the baseflow recession constant sets the release.

Use real gage data

The five regimes above are synthetic. Each one runs a two-reservoir model (quickflow plus a slow groundwater store) driven by seeded random storms and a snowmelt pulse, tuned to look like that kind of stream. They are not records from any gage.

Straight from USGS. Type a gage's site number and a water year, then fetch. The page asks the USGS Water Data API for that year's daily mean discharge, and falls back to the older NWIS daily-values service if it has to. Nothing is sent anywhere else.

Find site numbers on the USGS Water Data map. 09241000 is the Elk River at Clark, Colorado.

Or load a file. To play a real stream from a file, load one water year of daily discharge. The page reads USGS RDB tab-delimited files, or any CSV with a date column (YYYY-MM-DD) followed by a discharge value. If the file spans several water years, choose one from the menu that appears. Gaps are filled by linear interpolation.

For offline use, the script fetch_usgs.py downloads one water year from USGS and writes that CSV. It uses only the Python standard library. Run it on a computer that can reach USGS:

python fetch_usgs.py 09241000 2023

The arguments are a USGS site number and a water year. The script tries the USGS Water Data OGC API first and falls back to the legacy NWIS daily-values service. You can also drop a file anywhere on this page.
