Sound It Out

Tap a letter. Only the letters that can keep a real word going will show up next. A friendly robot says each sound as you add it, then blends the sounds into the whole word.

How it works

Behind the game is a little tree of every short‑a word. At each step it offers only the letters that still lead somewhere, so you can never build a non‑word. When the letters so far spell a real word, Say it lights up: it plays each letter's sound in turn (c… a… t) and then the same sounds stitched fast into the word (cat), the way reading is taught — sound, then blend.

The robot voice is generated with ElevenLabs once (a clear voice with a light robot effect), saved as one small clip per sound; the game plays and stitches them, so it works offline and sends nothing. Because words are built from the sounds, more word families need only their letter sounds recorded.
