Use FluidTA in your class

Every page here can live inside your course. The quickest way is an embed link. If your LMS speaks LTI 1.3, there's a one-click activity option too.

Build an embed link

Pick a page and copy the link into your LMS's "embed" or "external URL" box. In embed mode the page drops its own menus and sits cleanly in the frame.


The LTI 1.3 activity

A single sign-on activity that appears in your course needs a tiny server to receive the launch, because this site is static and a launch arrives as a POST that static hosting can't read. That server is a small Cloudflare Worker in the repository — deploy it once, then register these URLs in your LMS (replace <worker> with the address it gives you):

OIDC login URLhttps://<worker>/login
Redirect / Target Link URIhttps://<worker>/launch
Public JWK Set URLhttps://<worker>/jwks
Config JSON (Canvas)https://<worker>/config

To point an activity at a particular page, set the custom field fta_page to its file name (for example fta_page=hydrograph-synth.html), or set the activity's URL to that page. The Worker opens the page in the same embed mode as above, after checking the launch is genuine.

It's a content launch: it shows the page. It doesn't send grades back or use Deep Linking — the README covers setup for Canvas and Moodle and where those extensions would go.

Nothing a student does in an embedded page is sent anywhere; the pages run entirely in the browser. The LTI Worker checks the launch token and then steps out of the way.
